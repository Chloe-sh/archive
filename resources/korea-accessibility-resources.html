Digital Accessibility · Korea

국내 디지털 접근성 자료 모음

웹·모바일 접근성 작업에 참고할 만한 국내 표준, 기업 실무 자료, 해설 콘텐츠를 한자리에 모았습니다. 제목을 누르면 바로 이동합니다.

01표준 · 지침 원문

공식 기준이 필요할 때 — 가이드라인 개발, 제안서 근거, 인증 대응

  • 한국형 웹 콘텐츠 접근성 지침 (KWCAG) 2.2

    국가표준 최신판을 웹에서 읽기 좋게 정리한 문서. 같은 저자의 WCAG 2.2 한국어 번역본과 함께 보면 국제 기준과 비교하기 좋습니다.

    국가표준필수
  • 한국디지털접근성진흥원 (KWACC)

    웹 접근성 품질인증 지표와 심사 기준. 인증 요건 관점에서 무엇을 점검받는지 확인할 때 유용합니다.

    품질인증
  • 한국지능정보사회진흥원 (NIA) — 접근성 국가표준 개정 안내

    웹 접근성 국가표준을 관리하는 기관. 표준 개정 배경과 주요 변경 사항을 확인할 수 있습니다.

    공공기관

02기업 실무 자료

실제 서비스에 적용한 사례 중심 — 체크리스트, 대체 텍스트, 스크린리더 대응

  • 널리 (NULI) — 네이버 접근성 커뮤니티

    국내에서 가장 자료가 풍부한 곳. 모바일 앱 접근성 지침 해설, 체크리스트, 대체 텍스트 작성 가이드, 교육 콘텐츠까지. 접근성 참고 URL 모음과 모바일 앱 접근성 지침 2.0 해설부터 보세요.

    네이버추천 시작점UX 라이팅
  • 카카오페이 기술 블로그 — 모두를 위한 접근성 이야기

    실무자 시선으로 쓴 접근성 적용기. 카카오 본사도 디지털 접근성 책임자(DAO) 선임 이후 관련 자료를 꾸준히 내고 있습니다.

    카카오실무 사례

03해설 · 번역 콘텐츠

원문보다 읽기 편한 풀이 — 입문, 팀 공유, 교육용

  • pxd 블로그 — KWCAG 2.2 해설

    디자이너 관점에서 지침을 풀어낸 글. 지침 원문이 딱딱하게 느껴질 때 먼저 읽기 좋습니다.

    디자이너 관점
  • UXKM — 접근성 가이드라인

    KWCAG를 항목별로 정리한 참고 사이트. 특정 항목을 빠르게 찾아볼 때 편합니다.

    항목별 정리
  • Web Soul Lab — 웹 접근성 지침 2.2

    접근성 전문 업체가 정리한 지침 요약. 검사 항목 기준으로 훑어보기 좋습니다.

    요약
어디서부터 볼까요? 입문이라면 pxd 해설 → 널리 순서로, 실무 적용이라면 KWCAG 2.2 원문과 널리 체크리스트를 함께 보는 것을 권합니다. UX 라이팅 쪽은 널리의 대체 텍스트 작성 가이드가 가장 실속 있습니다.
