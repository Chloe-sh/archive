01. 확정 용어

확정 · 즉시 적용

통합해충방제
‘S-IPM’은 내부 용어입니다. 모든 해충방제 서비스의 대외 명칭을 ‘통합해충방제’로 통일합니다.
권장: 통합해충방제로 사업장의 해충 문제를 체계적으로 관리합니다.
S-IPM / IPM / 스마트 통합해충방제
대외 사용 금지
프로젝트명, 작업 파일명 등 내부 관리 범위에서만 사용합니다. 고객 노출 카피에서는 ‘통합해충방제’로 바꿉니다.
점검 위치: 카드뉴스 제목, 본문, 해시태그, 이미지 대체텍스트, CTA, 메타데이터

02. 브랜드·서비스·제품명

세스코 / CESCO
사용 가능
국문 본문에서는 ‘세스코’를 기본으로 사용합니다. 영문 로고·법정표기 등 지정 영역은 ‘CESCO’를 유지합니다.
세스코 마이랩 / CESCO Mylab
반복 확인
소비재 브랜드명. 국문 카피에서는 ‘세스코 마이랩’, 영문 브랜드 블록에서는 ‘CESCO Mylab’ 표기가 반복 사용되고 있습니다.
세스코 과학연구소 ↔ 세스코 생활과학 연구소
공식 명칭 확인 필요
작업물에서 두 명칭이 혼용됩니다. 조직의 공식 명칭과 브랜드 서사에 쓸 표현을 구분해 확정해야 합니다.
세스코 마이랩 마스터 차량용 전문탈취제
라벨 기준 확인
‘차량용 탈취캔’과 ‘마스터 차량용 전문탈취제’가 함께 등장합니다. 대외 제품명은 실제 라벨·품목신고 명칭을 우선합니다.
세스코 마이랩 살균소독제
제품명 확인
현재 상세페이지 작업물 표기. 띄어쓰기와 품목명은 라벨 최종본 기준으로 등록합니다.
세스코 마이랩 이염방지시트
제품명 확인
현재 상세페이지·리플릿 작업물에서 일관되게 사용 중입니다. 최종 라벨과 대조 후 확정합니다.
세스코 마이랩 항균 쿨링 데오티슈
제품명 확인
‘데오티슈’ 붙여쓰기를 포함해 최종 패키지 표기와 대조가 필요합니다.
세스코 블루쉴드 에어커튼
서비스 결합명 확인
제품명은 작업물에서 반복 확인됩니다. ‘비래해충 솔루션’, ‘통합해충방제 솔루션’ 등 결합 서비스 표현은 이번 통일 원칙에 맞춰 별도 정리가 필요합니다.
세스코 THE슬림 / THE맥스 정수기
영문 조합 확인
‘THE슬림 & THE맥스’, ‘세스코워터’가 함께 사용됩니다. 개별 제품명, 라인업명, 사업 브랜드명의 위계를 정해 등록해야 합니다.

03. 가이드 반영 규칙

통제어휘 등록 단위
운영 제안
각 항목을 ‘권장어 / 비권장어 / 정의 / 사용 범위 / 예문 / 근거 / 확정일 / 담당 부서’로 관리합니다. 제품명은 라벨·계약서·공식 웹사이트 중 어느 자료가 최우선인지도 함께 기록합니다.
제작물 검수 체크
운영 제안
본문뿐 아니라 파일명, 도판 안 텍스트, 표·각주, CTA, URL slug, alt text까지 같은 명칭을 적용합니다. 내부 용어가 필요한 경우 고객 비노출 메모에서만 사용합니다.
