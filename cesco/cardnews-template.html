세스코 카드뉴스 표준 템플릿 : 기본 8장 · 최대 10장

어떤 위생 주제가 와도 같은 틀에 채워 넣으면 카드뉴스가 완성되는 표준 구조입니다.
독자 심리 흐름(후킹 → 신뢰 → 필요성 인식 → 셀프팁 → 제품 → 전환)에 맞춰 역할 블록을 고정 배치합니다.

목적 (고객사 가이드) : 고객에게 전문 위생 정보를 전달하고 관리의 필요성을 강조합니다. 주로 숫자·통계 등 근거 데이터를 활용합니다.
⚠ 가장 중요한 원칙 : 근거는 권위 있는 출처에서만. 모든 수치·통계·주장은 식약처·질병관리청(KDCA)·통계청·환경부 등 정부·공공기관, 학회, 학술 논문, WHO·EPA 등 국제기구 같은 1차·권위 출처에서만 가져옵니다. 개인 블로그·커뮤니티·출처 불명 기사는 근거로 쓰지 않으며, 출처를 찾을 수 없는 수치는 아예 쓰지 않습니다. 표기는 기관/저자명+자료명+연도.

06프롬프트 운영 흐름

상세페이지와 동일하게 단계를 쪼개, 중간마다 사람이 검토할 여지를 둡니다. 자료가 부족하면 1B(자료 탐색·보강)로 웹검색을 거쳐 근거를 채웁니다. (전체 프롬프트는 가이드 .md 4장 참조)

1
정보 구조화
원본 자료 → JSON 스키마로 정리. "지어내지 마" 명시
1B
자료 탐색·보강
빈칸이 남으면 웹검색 도구로 근거 조사. 공공·1차 출처 + URL·연도 검증(4-1B)
2
마스터 생성
JSON → 전체 카피 원샷 생성(기본 8장·최대 10장)
3
장별 재작업
표지·문제인식·셀프팁 등 특정 장만 재생성
4
헤드라인 점검
동어 반복 지양(3회 미만 허용) + "헤드라인만 읽어도 이해" 일괄 검수
5
컴플라이언스
"심의 담당자" 역할로 과장·의료 단정 표현 걸러내기

07이 구조가 작동하는 4가지 원리

권위 있는 근거로 신뢰를 산다
모든 수치를 식약처·질병관리청·통계청·학회·논문 같은 1차·공공 출처에서만 인용합니다. 근거의 권위가 곧 세스코 콘텐츠의 신뢰이며, 출처 불명 수치는 오히려 신뢰를 깎습니다.
셀프팁이 전환의 경첩
무료 팁을 준 뒤 마지막 항목의 "일상 관리 한계"가 제품 소구의 명분을 만듭니다. 정보와 제품 사이 자연스러운 다리입니다.
헤드라인만으로 스토리
각 장 헤드라인이 헤드라인만 읽어도 카드 내 내용이 이해되고 불필요한 동어 반복이 없으면, 빠르게 넘겨도 전체 메시지가 전달됩니다.
브릿지로 이어지는 흐름
도입·문제인식 카드는 다음 카드로 이어지는 브릿지 문구로 끝맺습니다. 앞 카드의 마지막 문장이 다음 카드의 첫 문장을 불러, 이탈 없이 끝까지 읽히게 합니다.

08발행 전 최종 체크리스트

구조 · 전환 · 근거

  • 표지 헤드라인이 문제제기형 + 핵심 숫자를 담았는가
  • 표지 부제가 전체 내용을 예고하는 건조체인가
  • 2장에서 표지 후킹을 받아주는 근거·출처가 있는가
  • 앞 카드 마지막 문장과 다음 카드 첫 문장이 자연스럽게 연결되는가 (브릿지)
  • 각 장 헤드라인만 읽어도 카드 내 내용이 이해되는가 (동어 반복은 지양, 3회 미만 허용)
  • 모든 수치가 권위 출처(식약처·질병관리청·통계청·환경부·학회·논문·WHO/EPA)에서 왔는가
  • 개인 블로그·커뮤니티·출처 불명 기사에서 온 수치가 섞이지 않았는가
  • 검색으로 새로 채운 수치(1B)는 원문 URL·연도까지 사람이 교차 확인했는가
  • 모든 근거에 기관/저자명+자료명+연도가 표기됐는가
  • 대상 강조 장에서 타깃별 추가 위해성·특별 관리 대상으로 위기감을 개인화했는가
  • 셀프팁 헤드라인이 "이렇게 관리해 보세요"인가
  • 셀프팁 마지막이 "일상 관리 한계 → 제품"으로 연결되는가
  • 제품이 마지막 2장(Why 세스코·CTA)에서만 노출됐는가
  • 맺음말에 명확한 CTA가 있는가
  • 표현 수위가 '경각심 유도' 범위인가 (협박·단정·혐오 비유 없음)
  • 컴플라이언스 QA로 과장·의료 단정·공포 조장을 걸렀는가
