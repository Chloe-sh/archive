03
Why 세스코 → 왜 전문가 진단이 필요한가 대체
일치함제안

원본 실제 이미지 · 왜 전문가 진단이 필요한가 (타겟 공감에서 이동)

해충방제=세스코가 자명해 브랜드 소개형 "왜 세스코?"는 불필요. 가이드 서비스 분기의 대체 블록인 "왜 전문가 진단이 필요한가"가 이 페이지에 이미 존재합니다 - 타겟 공감 이미지 하단의 "세스코는 다르게 시작합니다" + 확인 4항목(언제·왜·어디서 발생했는지 / 무엇을 좋아하는지 / 어디까지 숨어있는지 / 다른 위험은 없는지)이 정확히 이 역할을 수행 중이며, 위치도 가이드 서비스 순서(공감 → 진단 필요성)와 일치합니다.

적용 방향: "해충을 마주한 순간, 누구나 고민이 시작됩니다" 이미지(고민 인용 + "세스코는 다르게 시작합니다" 확인 4항목)를 ③ 대체 블록으로 이동했습니다. 인용 3개(스스로 해결의 한계)가 도입, "다르게 시작합니다" 4항목이 본론이 되어 "왜 전문가 진단이 필요한가" 논증이 한 장 안에서 완성되는 구조라 재제작 없이 블록 매핑 변경만으로 충분합니다. 확인 4항목을 이미지 아래 텍스트로 반복하면 GEO까지 확보됩니다.

04
타겟 공감 신뢰형성
일치함내용 수정

④ 타겟 공감은 "이런 분께 추천해드립니다" 체크리스트가 담당합니다. 내용 수정: 6개 항목(해충 발견 걱정 / 체계적 진단 희망 / 약 써도 재발 / 타사 실패 / 이사·입주 전 점검 / 사업장 위생점검)을 "약을 써도 자꾸 다시 보인다면"처럼 상황이 그려지는 문장형으로 다듬어 공감 블록 역할을 온전하게 만듭니다.

추가 의견 · 가독성 제안 내용은 강한데 시각적으로 안 드러남(회색 체크 + 텍스트라 스캔이 안 됨). 3가지 제안:
  • 항목별 아이콘: 발견 / 재발 / 약제 / 타사실패 / 이사·입주 / 사업장 6개를 픽토그램으로
  • B2C·B2B 2열 분리: 가정(발견·재발·이사) vs 사업장(위생점검·오픈 전)으로 묶어 "내 상황"을 빨리 찾게
  • 트리거 문구 강조: "약을 써본 이후에도", "타 서비스 이용했는데" 같은 핵심구를 굵게/컬러로
