섹션별 상세 스펙각 섹션은 (a) 원칙 · (b) 카피 공식 · (c) 실제 예문 · (d) 지킬 것과 피할 것 순으로 정의된다

①

문제 제기 헤드라인

a 원칙

세 가지 진입 패턴: (i) 뉴스 헤드라인 말풍선 + 효능 헤드, (ii) 문제 단정 + ‘A는 다릅니다’ 재프레이밍, (iii) 브랜드 헤더 + 기술 수식 상품명(프리미엄 가전형).

b 카피 공식
  • (i) [말풍선] {뉴스 헤드라인} ×3 + {병원체 나열} 살균하는 / 세스코 {상품명}
  • (ii) 잡아도 또 나타나는 {해충}, / {범위 확장: 알부터 번데기까지} 제어하는 / 세스코 솔루션은 다릅니다.
c 실제 예문
  • 패턴 i — 뉴스 말풍선 + 효능 헤드 폐렴균·독감·코로나 바이러스 살균하는 / 세스코 공기살균기343

②

근거·심각성

a 원칙

불안 환기를 감정어가 아닌 수치·생태로 수행. ✅ 소제목(질문형 허용) + 근거 문단 또는 수치 카드 3개.

b 카피 공식
  • 질문 소제목 ✅ {해충/문제}, 왜 자꾸 생겨날까요? → 즉답: {원인 원리}에서 시작해야 근본 원인을 해결할 수 있습니다.
  • 수치 카드 {라벨 명사구} / {수치 주장}* (카드 3개: 주기·번식력·서식지)
  • 유행 서술 {병원체}는 {주기·양상}으로 유행을 반복합니다. … {상품}은 {병원체}가 당신을 공격하기 전에 {기술}이 가동되어 {대상}을 선제공격합니다!
c 실제 예문
  • 질문 소제목 + 수치 카드 3개 ✅ 얼룩점초파리, 왜 자꾸 생겨날까요? / 해충의 습성에서 시작해야 근본 원인을 해결할 수 있습니다. // 초단기 생애 주기(2주) 빠른 개체 수 증가 및 확산 / 폭발적 번식력 암컷 1마리 당 약 500개 산란* / 은밀한 서식지 배수관이나 틈새에 쌓인 유기물, 음식물 찌꺼기 등에 유충과 번데기 주요 서식400
  • 유행 서술 + 해법 선언 인플루엔자 바이러스에 의한 ‘독감’이 매년 유행하고 있으며, 사망원인 3위(출처: 통계청 2022)인 폐렴은 3~5년 주기로 환절기마다 유행을 반복합니다. … 세스코 공기살균기는 공기 중 폐렴균, 독감, 코로나 바이러스가 당신을 공격하기 전에 첨단 UV살균터널이 가동되어 바이러스와 세균을 선제공격합니다!343
  • 수치 선언 인용형 환절기마다 유행하는 독감 인플루엔자(H1N1)바이러스 99.99% 살균, / 각종 호흡기 질환 유발하는 폐렴균 99.9% 살균 / 계속 변이하며 확산을 멈추지 않는 코로나 바이러스 99.99% 살균343
d 체크

지킬 것

수치엔 즉시 * 또는 (출처: ) 병기. 군사 은유(선제공격·박멸)는 해충·병원체 대상에만.

피할 것

출처 없는 공포 수치, ‘무섭다·끔찍하다’ 류 감정어.
